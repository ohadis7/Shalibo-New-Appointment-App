# car-agent — סוכן מומחה רכב יד 2

סורק חיפושי יד 2, מתמחר כל מודעה מול השוק שלה ומדרג מציאות אמיתיות.
לא "הכי זול" — אלא **זול ביחס למה שהרכב באמת שווה, ובלי סיבה מפחידה לכך**.

## מה הוא עושה

1. **אוסף** — מריץ את החיפושים שהגדרת ביד 2 (עד N עמודים לכל חיפוש).
2. **מתמחר** — לכל קבוצת דגם בונה מודל רגרסיה `ln(מחיר) = b0 + b1·גיל + b2·ק"מ`,
   עם התאמה חוזרת בלי חריגים כדי שכמה מודעות הזויות לא יעוותו את הבסיס.
   התוצאה: מחיר צפוי לכל רכב, סטייה באחוזים, וחיסכון בשקלים.
3. **מסנן** — לפי מחיר/שנתון/ק"מ/יד/גיר/בעלות/אזור/מילות מפתח.
4. **מסמן דגלים אדומים** — כולל הכלל החשוב ביותר: מחיר נמוך מדי מהשוק
   (ברירת מחדל: מתחת ל-55% מהצפוי) הוא **חשד**, לא מציאה.
5. **מדרג** — ציון 0-100 המשקלל מחיר (60%), מצב (25%) וסיכון (15%).
6. **זוכר** — בין ריצות: מה חדש, ומי הוריד מחיר (האות הכי שווה שיש).

## התקנה

```bash
cd car-agent
npm install              # מוריד Playwright + Chromium (למצב browser)
cp config.example.json config.json
```

אם כבר יש Chromium במכונה:
```bash
npm install playwright-core
export CHROMIUM_PATH=/path/to/chrome
```

## שימוש

```bash
node src/cli.js                       # ריצה מלאה לפי config.json
node src/cli.js --config config.hatchback.example.json   # פריסט: יאריס/אוריס/ג'אז ודומים
node src/cli.js --config config.demo.json                # דמו offline על נתוני בדיקה
node src/cli.js --top 20              # יותר תוצאות
node src/cli.js --new-only            # רק מודעות שלא נראו בריצה קודמת
node src/cli.js --min-score 70        # רק מציאות חזקות
node src/cli.js --mode file --file fixtures/sample-feed.json   # הרצה offline
npm test                              # בדיקות
```

פלט: טבלה בטרמינל + `out/report.html` (עברית RTL, תפריט המבורגר לסינון ומיון) + `out/report.json`.

## הגדרות (`config.json`)

### חיפושים
**הדרך הנכונה להגדיר קריטריונים**: בונים את החיפוש באתר יד 2 עצמו, מעתיקים את ה-URL
מהדפדפן ומדביקים ל-`searches[].url`. כך לא צריך לנחש קודי יצרן/דגם, והם לא נשברים
כשיד 2 משנה אותם.

```json
"searches": [
  { "name": "טויוטה",
    "url": "https://www.yad2.co.il/vehicles/cars?manufacturer=19&year=2015-2022&price=25000-90000",
    "maxPages": 4,
    "expect": ["יאריס|yaris", "אוריס|auris"] }
]
```

`expect` הוא **בדיקת שפיות**: אם פחות מ-30% מהמודעות שחזרו תואמות את הדגמים שציפית
להם, הסוכן מתריע שקוד היצרן/דגם ב-URL כנראה שגוי או השתנה — במקום להחזיר בשקט את
הרכבים הלא נכונים.

### שתי גישות להגדרת דגמים

| גישה | מתי |
|---|---|
| URL ברמת **דגם** (`manufacturer=19&model=...`) | פחות עמודים לסרוק, אבל נשבר כשקוד הדגם משתנה |
| URL ברמת **יצרן** + `filters.modelPatterns` | **מומלץ.** סורק יותר, אבל הצמצום נעשה לפי שם הדגם במודעה עצמה — תמיד נכון |

הפריסט `config.hatchback.example.json` משתמש בגישה השנייה.

### סינון (`filters`)
מופעל מקומית על התוצאות, אז הוא תמיד מדויק גם אם פרמטר ב-URL השתנה.

| שדה | משמעות |
|---|---|
| `priceMin` / `priceMax` | טווח מחיר |
| `yearMin` / `yearMax` | טווח שנתון |
| `kmMax` | קילומטראז׳ מקסימלי |
| `handMax` | מספר ידיים מקסימלי |
| `gearbox` | `["auto"]` / `["manual"]` |
| `modelPatterns` | רשימת שמות דגם (טקסט או regex, עברית או אנגלית) — משאיר רק אותם. ריק = בלי סינון דגם |
| `excludeOwnerTypes` | `rental`, `leasing`, `driving-school`, `company`, `private` |
| `excludeDealers` | `true` = רק מודעות פרטיות |
| `regions` | רשימת אזורים (התאמה חלקית לשם) |
| `excludeKeywords` / `requireKeywords` | מילים בתיאור המודעה |

### ניקוד (`scoring`)

| שדה | משמעות |
|---|---|
| `minBargainScore` | הסף שממנו רכב נספר כ"מציאה" (ברירת מחדל 60) |
| `topN` | כמה תוצאות להדפיס |
| `weights` | `value` / `condition` / `risk` — מנורמלים אוטומטית |
| `tooGoodToBeTrueRatio` | מתחת ליחס הזה מול הצפוי — דגל אדום (0.55) |
| `kmPerYearNormal` | ק"מ שנתי "נורמלי" להשוואה (15,000) |

### איסוף (`fetch`)

| מצב | מתי |
|---|---|
| `browser` | **ברירת מחדל.** Chromium אמיתי, קולט את קריאות ה-feed של הדף. שורד את Cloudflare. |
| `http` | קריאה ישירה ל-`gw.yad2.co.il`. מהיר, אבל בדרך כלל ייחסם. |
| `file` | קורא JSON/HTML שמור מהדיסק. לפיתוח, לבדיקות, וכמוצא אחרון (שמור את הדף מהדפדפן שלך). |

`delayMsBetweenPages` הוא השהיה אקראית בין עמודים — אל תקטין אותו.

## פריסט מוכן: סופרמיני וקומפקטיות

`config.hatchback.example.json` — יאריס, אוריס, הונדה ג'אז, סוויפט, באלנו, מאזדה 2/3,
i20/i30, ריו, פיקנטו, סיד, מיקרה, נוט ודומים. 2015-2022, אוטומט, עד 140,000 ק"מ,
עד יד 3, ₪25,000-90,000.

```bash
cp config.hatchback.example.json config.json
# ערוך את הטווחים בראש הקובץ, ואז:
node src/cli.js
```

**קודי היצרן ב-URLים של הפריסט הם נקודת פתיחה ולא מאומתים.** אם קיבלת אזהרת
"כנראה קוד יצרן/דגם שגוי" — פתח את יד 2, בחר את היצרן מהתפריט, והעתק את ה-URL
מהדפדפן לתוך `searches[].url`. הסינון לפי `modelPatterns` ימשיך לעבוד בלי שינוי.

בעלות קודמת מסוג השכרה/ליסינג **לא** מסוננת בפריסט — בסגמנט הזה זה חלק גדול
מהמלאי ולפעמים מציאה אמיתית. הציון מוריד להם נקודות ומסמן דגל, ואתה מחליט.
אם אתה בכל זאת לא רוצה אותם: `"excludeOwnerTypes": ["rental", "leasing", "driving-school"]`.

## ריצה מתוזמנת

```cron
0 8,20 * * *  cd /path/to/car-agent && /usr/bin/node src/cli.js --new-only --quiet >> out/agent.log 2>&1
```
`--new-only` מבטיח שתראה רק מה שנוסף מאז הריצה הקודמת. `out/seen.json` שומר גם
היסטוריית מחירים, כך שירידת מחיר על מודעה ותיקה מסומנת בדוח.

## איך לקרוא את הציון

| ציון | פירוש |
|---|---|
| 75+ | מציאה — שווה טלפון היום |
| 60-74 | שווה בדיקה |
| מתחת ל-60 | מחיר שוק |
| דגל "סיכון גבוה" | ציון גבוה אבל `risk ≥ 45` — כמעט תמיד יש סיבה למחיר |

**לפני שקונים:** דוח היסטוריה (משרד התחבורה / קרפרו), בדיקה במכון מורשה, ובדיקת
שעבודים. הסוכן מוצא מועמדים; הוא לא תחליף לבדיקה.

## מגבלות — חשוב לקרוא

- **ליד 2 אין API ציבורי** והם חוסמים סקרייפינג. מצב `browser` מתוכנן להיראות
  כמו גלישה רגילה ולכבד קצב, אבל השימוש הוא באחריותך ובכפוף לתנאי השימוש שלהם.
  אל תעלה את הקצב ואל תריץ בתדירות גבוהה.
- **הפרסר לא נעול לסכימה.** יד 2 משנים שמות שדות מדי כמה חודשים, ולכן
  `src/parse.js` מזהה מודעות לפי צורה ומושך שדות לפי התאמת דפוסים לנתיבי מפתחות.
  שינוי שם בדרך כלל עולה עוד דפוס אחד ברשימה שם.
- **מודל התמחור לומד מהמודעות שנאספו** — לא ממחירון לוי יצחק. חיפוש רחב יותר =
  הערכה טובה יותר. מתחת ל-8 מודעות בקבוצה הוא נופל לחציון, ומתחת ל-3 אין הערכה
  (השדה `confidence` בדוח משקף את זה).
- **מחיר מודעה ≠ מחיר עסקה.** הסטייה שמוצגת היא מול מחירי מודעות אחרות.
